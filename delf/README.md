# DELF B2 · DALF C1 준비 프로그램 (v1)

`index.html` 을 브라우저로 열면 바로 실행됩니다. 서버·설치 필요 없음.

## 폴더 구조

```
DALF 준비하기/
├─ index.html            학생 화면 (접속 코드 → 이름·거주지 입력 → 개인 대시보드)
├─ admin.html            선생님 전용 (관리자 코드 필요, 학생에게 노출되지 않음)
├─ data/
│   ├─ themes.js         주제·소주제 목록 + 시험 형식/시간
│   ├─ vocab.js          주제별 일반 어휘 (레벨별 100개)
│   ├─ examples.js       어휘 예문 (단어 → 문장)
│   ├─ dossiers.js       소주제별 자료집 (전문 어휘 포함)
│   ├─ frequency.js      기출 문제 근거 (2차 자료 교차)
│   ├─ sante-vocab.js    ★ La santé 주제 일반 어휘 B2 100 + C1 100 (예문 포함)
│   ├─ sante-dossiers.js ★ La santé 자료집 17개 (B2 10 + C1 7)
│   ├─ sante-sub-*.js    ★ La santé 소주제별 전문 어휘 17 × 100개 (예문 포함)
│   ├─ sujets.js         ★ La santé 시험 문항
│   ├─ medias-vocab.js   ★ Les médias & Internet 주제 일반 어휘 B2 100 + C1 100
│   ├─ medias-dossiers-*.js ★ Les médias 자료집 17개 (B2 12 + C1 5)
│   ├─ medias-sub-*.js   ★ Les médias 소주제별 전문 어휘 17 × 100개
│   └─ medias-sujets.js  ★ Les médias 시험 문항 25개
└─ 8-5 Le subjonctif.mp4 (원본 강의 영상)
```

데이터는 전부 `data/` 안의 JS 파일입니다. 학생과 매일 조금씩 채워 넣을 때
**`index.html`은 건드리지 않고 `data/` 파일만 편집**하면 됩니다.

## 화면

학습 흐름: **어휘(무장) → 주제표 자료집(논쟁 구조 파악) → 시뮬레이터(실전)**. 메뉴 순서도 이 흐름을 따릅니다.

### 화면 이동
- 모든 화면 이동이 주소(#해시)에 기록되므로 **브라우저 뒤로/앞으로가 그대로 동작**합니다.
  헤더의 ← → 버튼, `Alt+←` / `Alt+→` 도 같습니다.
- 자료집 팝업도 하나의 이동 단계입니다 — X, ESC, 뒤로가기 모두 이전 화면으로 돌아갑니다.
- 자료집 안의 «전문 어휘 100개»는 **새 창**으로 열립니다. 읽던 자료집은 그대로 남습니다.

| 화면 | 하는 일 |
|---|---|
| 대시보드 | 진도율, 오늘 할 소주제, 모의시험 기록 |
| 주제표 | **자료집 전용**. 상단 주제 메뉴(어휘 페이지와 같은 형태 — «전체 주제 보기» 또는 주제 하나). 소주제 클릭 → 자료집 팝업(상단 메뉴는 계속 보임, X 또는 ESC로 닫기). 주제명 클릭 → 그 주제의 어휘 화면으로 이동. 주제 행에 «0/100 암기» 고정 표시. ● 클릭 = 미학습→학습중→완료 |
| 기출 문제 | A/B/C 등급의 근거와 사용한 자료 전체 목록 |
| 어휘 | 단어 학습의 유일한 장소. 주제 선택 → 「주제 일반 어휘」 또는 「소주제 전문 어휘」 각 100개(예문 포함), 체크 암기, 플래시카드 |
| 시험 시뮬레이터 | 주제(어휘 페이지와 같은 메뉴) → 영역 선택 → 문항 무작위 출제. **Production orale은 전용 화면** — 준비 타이머 → 발표 녹음(개입 없음) → 전사와 말하기 지표(mots/min · 멈춤 · euh) → 자료집이 들어간 «시험관 프롬프트 복사» → ChatGPT 음성 모드에서 토론 → 피드백 붙여넣어 기록. **마이크는 https 에서만 동작합니다**(로컬 file:// 은 브라우저가 차단). 영역별 공식 시간 타이머, 작문 단어 수 카운터, 구술 준비/발표 2단계, 답안 자동 저장 |
| 학습 플랜 | 남은 소주제를 30/45/60일에 자동 배분 |

진행 상황은 브라우저 localStorage에 저장됩니다. 헤더의 **내보내기/불러오기**로
JSON 백업 → 다른 PC로 옮기거나 학생과 주고받을 수 있습니다.

## 주제 하나를 채우는 방법 (La santé가 기준)

주제 하나당 파일 두 개를 만들고 `index.html` 아래쪽 script 목록에 한 줄씩 추가합니다.

- `data/<주제>-vocab.js` — `Object.assign(window.VOCAB, {<키>:{B2:[...], C1:[...]}})`
  각 항목은 `[프랑스어, 한국어, 예문]` 세 칸.
- `data/<주제>-dossiers.js` — `Object.assign(window.DOSSIERS, {"<테마id>::<소주제>":{...}})`

키는 테마 id에서 `b2-`/`c1-`를 뗀 값입니다 (`b2-sante` → `sante`).

### 학생 화면 / 관리자 화면
- **index.html (학생)** — `accessCode` 입력 → 이름·거주지·마지막 취득 자격증 입력 → 개인 대시보드.
  거주지 시간대로 «공부 N일차»와 인사말이 계산됩니다. 선생님 관련 기능은 화면에 전혀 없습니다.
- **admin.html (선생님)** — `teacherCode` 필요. 학생이 보낸 «진도 코드»를 붙여넣으면 그 학생의 대시보드가 생성되고,
  «콘텐츠 현황» 탭에서 주제별 작성 상태와 미작성 목록을 볼 수 있습니다.

admin.html 탭: **대시보드**(선생님 홈 — 오늘 공부한 학생, 합계 시간, 평균 진도, 미접속 경고, 학생 한눈에 보기)
· **학생 현황**(코드 등록 + 학생별 상세) · **콘텐츠 현황**(주제별 작성 상태).

진도 전달: 학생 대시보드 하단 «진도 코드 복사» → 카톡 등으로 전송 → admin.html «학생 현황»에 붙여넣기.
(서버가 없어서 학생 데이터가 학생 브라우저에만 있기 때문입니다. 자동 동기화는 로그인·서버 도입 시점에.)

### 접속 코드 — 서버에만 있습니다
- 코드는 **`data/config.js` 에 없습니다.** 브라우저에서 그대로 읽히기 때문입니다.
  Vercel 환경변수에만 있습니다: `DELF_SECRET` · `DELF_TEACHER_CODE` · `DELF_STUDENTS`(학생 명단 JSON) · `DELF_ACCESS_CODE`(선택).
- 학생이 코드를 넣으면 `/api/auth` 가 확인하고 **서명된 토큰**만 브라우저로 내려옵니다.
  브라우저에는 코드가 저장되지 않습니다(토큰과 학생 id만).
- 진도 API(`/api/progress`)는 토큰이 있어야 동작합니다.
  학생 토큰은 **자기 기록만** 읽고 쓸 수 있고, 선생님 토큰은 **모든 학생을 읽기만** 할 수 있습니다.
- 학생 추가: Vercel → Settings → Environment Variables → `DELF_STUDENTS` 수정 후 Redeploy.
  `[{"code":"SY26","name":"서윤","city":"제네바","tz":"Europe/Zurich","cert":"","certDate":""}]`
- 점검: `dourikim.com/api/auth?diag=1` → `{"configured":true,...}` (코드는 노출되지 않습니다)

### 로컬에서 배포 전 확인하기
로컬 파일(`file://`)로 열면 **코드를 묻지 않고 바로 들어갑니다.** 서버가 없기 때문입니다.
- 하단에 «로컬 — 배포 전 확인용» 표시가 뜹니다.
- 저장 칸이 `delf_prep_v2::local` 로 분리되어 **실제 학생 기록과 절대 섞이지 않습니다.**
- 진도 서버 저장은 꺼집니다. 마이크(구술 녹음)도 브라우저가 막으므로 배포 주소에서만 됩니다.
- admin.html 도 마찬가지로 코드 없이 열리지만, 학생 진도는 불러오지 못합니다(콘텐츠 현황·미리보기는 정상).
- **배포된 https 주소에서는 이 우회가 적용되지 않습니다** — 코드 확인은 그대로 서버가 합니다.

### 학생 화면 미리보기 (선생님)
admin.html → «학생 현황» → **학생 화면으로 보기**. `index.html?preview=SY26` 이 새 탭에서 열리고,
학생이 보는 화면 그대로 조작할 수 있습니다. 기록은 `preview::` 칸에만 남아 **학생 데이터를 건드리지 않습니다.**
관리자 코드를 통과한 브라우저에서만 열립니다 (다른 사람이 주소를 알아도 접속 화면이 뜹니다).

### 진도 자동 저장 (서버)
- `data/config.js` 의 `syncUrl:"/api/progress"` 가 켜져 있으면, **학생 코드가 곧 서버 키**입니다.
  공부할 때마다 자동으로 저장되고, 접속할 때 자동으로 내려옵니다 → 기기를 바꿔도, 브라우저 기록을 지워도 그대로 이어집니다.
- 화면 상단 오른쪽에 «자동 저장됨» 표시. 실패하면 «저장 안 됨»으로 바뀌고, 그때는 «진도 코드»가 백업입니다.
- 서버 쪽은 `api/progress.js` 한 파일 (사이트 저장소 루트의 `api/` 폴더). Upstash Redis 를 씁니다.
  Vercel 프로젝트에 Redis 를 연결하면 환경변수가 자동으로 들어오고, 연결 전에는 503을 돌려주므로
  **서버가 없어도 학습 페이지는 그대로 동작**합니다 (브라우저 저장만 사용).
- 허용 코드는 환경변수 `DELF_CODES` (예: `SY26,MJ26`). 없으면 `SY26`.
- 점검: `dourikim.com/api/progress?diag=1` → `{"store":true,"codes":["SY26"]}` 이면 정상.
- admin.html «학생 현황»은 이 서버에서 학생 진도를 **자동으로 불러옵니다** (2분마다 + «지금 새로고침»).
  진도 코드 붙여넣기는 자동 저장이 안 될 때를 위한 예비 수단으로 접어 두었습니다.

### 저장·복구
- 접속 코드는 한 번 통과하면 그 브라우저가 기억합니다 (다음부터 코드 화면이 뜨지 않음).
- 이름·진도·공부 시간은 모두 그 브라우저의 localStorage에 있습니다.
  **자동 저장이 꺼져 있으면** 브라우저 사이트 데이터를 지울 때 전부 사라집니다 (그때는 «진도 코드»로 복구).
- 복구: 학생이 받아둔 «진도 코드»를 접속 화면의 «전에 쓰던 기록 복구하기»에 붙여넣으면 그대로 되살아납니다.
  (코드에는 진도·어휘·공부 시간·메모·플랜이 모두 들어 있습니다)
- 초기화: 주소 뒤에 `?reset` 을 붙여 열면 그 기기의 기록을 지웁니다. 예) `dourikim.com/delf?reset`

## 자료집의 «읽을 자료»
1. **확인된 문서** — 실제 문서로 직접 가는 링크만 남깁니다(홈페이지 링크는 여기서 제외).
2. **권장 소스에서 검색** — 소주제 키워드로 바로 검색됩니다.
   `KBS World (fr)` 한국 뉴스를 프랑스어로 · `Mediapart` 탐사 · `TV5MONDE` ·
   `TV5 Apprendre` FLE 가공 뉴스 · `Metro (BE)` 벨기에 무가지 · `20 Minutes` 프랑스 무가지
3. **그 외 매체** — Google Actualités, Le Monde, France Info, Radio France, France 24, ARTE, Courrier international, YouTube
4. 홈페이지 수준의 기관 링크는 **그 사이트 안에서 이 소주제를 검색**하는 버튼으로 자동 변환됩니다.

## «기출 문제» 탭에 대해

DELF/DALF는 **공식 기출을 공개하지 않습니다.** 시험지는 회수되고 공개되는 것은
sujets d'exemple 몇 종뿐입니다. 따라서 A/B/C 등급은 기출 기록이 아니라
응시자 후기 취합 + 대비 사이트 지목을 교차시킨 **신호의 강도**입니다.
근거는 «기출 문제» 탭에서 항목별로 전부 볼 수 있습니다.
